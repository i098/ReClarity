# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We keep this project open and welcoming. Contribution is free of harassment for everyone.

## Standards

- Be respectful and constructive.
- Accept feedback with grace.
- Do not use sexualized language or imagery.
- Do not troll, insult, or harass.
- Do not publish private information of other people.

## Enforcement

Maintainers remove, edit or reject comments, commits and issues that break this code. Report a problem privately through a [GitHub security advisory](https://github.com/i098/ReClarity/security/advisories/new) or to the maintainer [@i098](https://github.com/i098). Maintainers review each report and keep the reporter private.
